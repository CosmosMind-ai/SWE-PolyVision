Adding an image caption removes link target
## 📝 Provide detailed reproduction steps (if any)

1. Add an image
2. Add a link on the image with an external target (target="_blank")
3. Add a caption to the image
4. The target="_blank" attribute is gone.

You can see a video [here](https://drive.google.com/file/d/1ejvFkguo1A-sbC4vmEguJJBiPnRCnk3e/view?usp=sharing) that shows the problem on your demo site.

### ✔️ Expected result

That the link target should be maintained. 

### ❌ Actual result

That the link target is removed.
