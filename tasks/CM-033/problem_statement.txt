Flow operation does not display templated field value without template mode enabled
### Describe the Bug

If a field value has been set to a template (.e.g. `{{$trigger.payload.card}}`) it will not show in the input field unless template mode is enabled

### To Reproduce

1. Create a Flow with a `webhook` and `read data` operation
2. Add a template of `{{$trigger.payload.id}}` for the `IDs` section of the read operation
3. Observe it showing in the Read Operation card preview
4. Attempt to edit the Read operation and observe the value is not showing unless template mode is enabled
