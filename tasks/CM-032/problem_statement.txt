Missing data if the distinct count is failing
### Describe the Bug

The collection page will not show any data if the distinct count (its result shown at the top right corner of the page) is not loaded in. If the distinct count fails, it won't show the data at all.

![Image](assets/directus__directus-26045/001.png)

I would consider the `x-y of z` visual a _nice to have_, but not critical for it to block the data visualisation all together.  For larger datasets, this feature keeps most collections empty for longer than needed, given that the actual query for the data itself is faster than the distinct count.

### To Reproduce

Create a large table if 1M entries. Open the collection through the CMS and observe the load times.

To 'break' the distinct count query can be a bit harder. Either reduce the performance of the database, or increase the number of entries.

### Directus Version

v11.6.1

### Hosting Strategy

Self-Hosted (Docker Image)

### Database

PostgreSQL 15.13
