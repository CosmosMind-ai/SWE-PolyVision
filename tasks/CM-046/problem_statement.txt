Shrink width of Heading level 6 causes it to jump up in size
<!--- Provide a general summary of the issue in the Title above -->
See https://grommet.slack.com/archives/C09QQEG69/p1595361593434100?thread_ts=1595361593.434100&cid=C09QQEG69

<!--- Tell us what should happen -->
For h6 elements, shrinking page width should not cause the font size to increase.

Thanks to Taylor Seamans for this explanation... (paraphrased)

...this is likely a boundary condition.  As the pages shrinks and crosses breakpoints, the theme's heading sizes are reduced.  Since "6" is the smallest, it can't go any smaller and I noted finds some defa t size.

### Actual Behavior

Shrinking page width causes font size to increase.

### Steps to Reproduce

Start with component `<Heading level="6">Hello Grommet</Heading>`.  Now shrink the page below the breakpoint of 768 and the font size increases.
