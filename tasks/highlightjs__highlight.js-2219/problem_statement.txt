(fortran) number before underscore disappears
If an underscore follows a number in formatted Fortran code, the number disappears. The code
````
e = init_pair(1_c_short, COLOR_YELLOW, COLOR_BLACK)
````
will be shown as
````
e = init_pair(_c_short, COLOR_YELLOW, COLOR_BLACK)
````
