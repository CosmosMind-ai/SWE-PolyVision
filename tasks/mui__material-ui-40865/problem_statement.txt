#### Comment at 2021-08-18T14:52:37Z

I am also running into issues with the `label` prop on `Select` elements. 

Issue 1: When I set a `label` prop, it doesn't show up in the output.
![Screen Shot 2021-08-18 at 10 23 10 AM](assets/mui__material-ui-40865/004.png)

Issue 2: When I use an `InputLabel`, the label appears struck-out:
![Screen Shot 2021-08-18 at 10 56 54 AM](assets/mui__material-ui-40865/005.png)

Code example:
```
const useStyles = makeStyles(theme => ({
    formControl: {
        minWidth: 120
    }
}));

export const Base = () => {
    const classes = useStyles();
    return (
        <FormControl className={classes.formControl} variant="outlined">
            <InputLabel>My Label</InputLabel>
            <Select onChange={action('change')}>
                <MenuItem value={1}>1</MenuItem>
                <MenuItem value={2}>2</MenuItem>
                <MenuItem value={3}>3</MenuItem>
            </Select>
        </FormControl>
    )
};
```

Workaround: Using both a `label` prop _and_ an `InputLabel` appear to render something that looks good. I just think there is a better way out there somehow.
![Screen Shot 2021-08-18 at 11 00 07 AM](assets/mui__material-ui-40865/006.png)

Code:
```
const useStyles = makeStyles(theme => ({
    formControl: {
        minWidth: 120
    }
}));

export const Base = () => {
    const classes = useStyles();
    return (
        <FormControl className={classes.formControl} variant="outlined">
            <InputLabel>My Label</InputLabel>
            <Select label="My Label" onChange={action('change')}>
                <MenuItem value={1}>1</MenuItem>
                <MenuItem value={2}>2</MenuItem>
                <MenuItem value={3}>3</MenuItem>
            </Select>
        </FormControl>
    )
};
```

Update: I see on the codesandbox of the reference documentation that both `InputLabel` element _and_ `label` prop on the `Select` are used to achieve the correct display. Kind of confusing!
