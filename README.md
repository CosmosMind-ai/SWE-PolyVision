# SWE-PolyVision Public Tasks

Public question package for SWE-PolyVision from CosmosMind AI Lab.

This release contains the 48 public candidates requested for the benchmark. Each task includes only the task statement, fixed repository revision, and visual evidence needed to inspect the issue. Developer patches, reference fixes, verifier assets, model results, traces, and answer materials are intentionally excluded.

The task statements are derived from the benchmark packages and scrubbed at the boundary before the pre-fix discussion/reference-fix section.
